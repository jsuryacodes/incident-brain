## 2. The prompt a client starts from

`prompts/get investigate_alert`:

> An alert fired on svc:payments-api: 5xx rate 12% and p99 4.1s for the last 15 minutes. Use the tools: find_service if you only have a name, then recent_changes (every change is a lead), recent_changes_downstream and shared_dependency_changes to keep or reject each lead with the graph, then who_to_call, blast_radius, decisions_about and past_incidents for the culprit, and rollback_safety before suggesting a rollback. Cite node ids from the results; say why you rejected each other change.
